# 4elemEJ

> Магическая match-3 головоломка о четырёх стихиях — целиком в одном HTML-файле.

`4elemEJ` — это полностью автономная мобильная игра в жанре «три в ряд». Собирайте ряды из огненных, водных, земных и воздушных символов, наблюдайте, как по собранным путям струится светящийся **Поток Стихий**, и наполняйте его энергией древний алтарь, пока не истекло время.

Игра написана на чистом JavaScript без единой внешней зависимости: вся графика рисуется кодом на Canvas, весь звук синтезируется через Web Audio API. Достаточно открыть `index.html` — и можно играть.

## ✨ Особенности

- 🌊 **Поток Стихий** — фирменная механика: по пути собранного ряда пробегает светящийся ручей, частицы энергии устремляются в алтарь и заполняют его шкалу
- 🔥💧🌿🌪️ **Четыре стихии** — каждый элемент со своим магическим свечением
- 🎯 **Три уровня сложности**:
  - *Ученик* — спокойная игра без таймера, цель — набрать очки
  - *Маг* — 90 секунд, чтобы заполнить алтарь
  - *Архимаг* — 60 секунд, поле 9×9 и ледяные оковы
- ❄️ **Ледяные оковы** — вмёрзшие кристаллы, которые нужно разбить двумя точными ударами
- 🔊 **Синтезированный звук** — звуковые эффекты и генеративная амбиент-музыка создаются на лету через Web Audio API
- 🏆 **Рекорды** — лучший результат сохраняется отдельно для каждой сложности
- 📱 **Мобильное управление** — свайпы, поддержка HiDPI, адаптация под любой экран и ориентацию
- ⚡ **Плавные 60 FPS** — игровой цикл на `requestAnimationFrame` с расчётом `deltaTime`

## 🎮 Как играть

1. Свайпом поменяйте местами два соседних элемента.
2. Соберите линию из 3 и более одинаковых стихий.
3. Энергия собранного ряда потечёт в алтарь — заполните его шкалу до победы.
4. Каскадные совпадения дают множитель очков ×2, ×3 и выше!
5. Кнопка 🔊/🔇 в правом верхнем углу управляет звуком и музыкой.

## 🚀 Запуск

Никаких зависимостей, сборки или сервера не требуется:

```bash
# Просто откройте файл в браузере
open index.html      # macOS
xdg-open index.html  # Linux
start index.html     # Windows
```

## 📦 Сборка в Android-приложение (APK)

Игра готова к упаковке через Apache Cordova:

```bash
npm install -g cordova
cordova create four-elem-ej com.yourname.fourelemej "4elemEJ"
cd four-elem-ej
cordova platform add android

# скопируйте index.html в папку www/ (с заменой стандартного)
cp /path/to/index.html www/

cordova build android
```

Готовый APK появится в `platforms/android/app/build/outputs/apk/debug/app-debug.apk`.

## 🛠 Технологии

| Компонент | Реализация |
|---|---|
| Графика | HTML5 Canvas API, процедурная отрисовка |
| Звук и музыка | Web Audio API (осцилляторы, огибающие, look-ahead секвенсор) |
| Архитектура | Паттерн State, конечный автомат игрового поля |
| Игровой цикл | `requestAnimationFrame` + `deltaTime` |
| Сохранения | `localStorage` (рекорды, настройки звука) |
| Зависимости | **Отсутствуют** |
